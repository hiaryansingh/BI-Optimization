      Performance Analyzer records time, not CU, so these are estimates: CU(s) = DAX seconds × the factor above. To calibrate, open the Microsoft Fabric Capacity Metrics app, find this report's interactive queries, divide their CU(s) by their duration in seconds, and enter the result.                 1 · Three kinds of instructions, like building a house
                
      
                
        
                🧱
                HTML · the walls and rooms
                Says what is on the page: a heading here, a button there, a table below. Without anything else it looks plain, like a house with bare brick walls.

                Is each visual right for its business question?
                
      
                Each visual is checked against the question it should answer, guessed from its fields: a trend, a comparison, a share, a single number, exact records. When another visual answers that question better, you get the suggestion, the steps to change it, and how much lighter it is to load. Change the question on any visual if the guess is wrong, or describe the decision it supports and ask Claude.
                
      
                
        
        
        
        
                
      
                
    
                
    
                
    
                
    
                Based on Microsoft's guidance on which visual suits which question and the performance guidance in the playbook. Visual sizes and formatting aren't judged; the check is about the question, the data shape, and load cost.
                
  
                

  
  
                
    
                
      
                Apply fixes to your model
                
      
                  
        
                1. Review the changes below. Untick anything you don't want. Changes marked Review can change numbers, so they start unticked.
                  2. 
        
                2. For a .pbix: open it in Power BI Desktop, go to TMDL view, open a new tab, paste the script, and select Apply. Check your visuals, then save.
                  3. 
        
                3. For a PBIP project: download the fixed files, replace the ones in your project folder, and reload when Power BI Desktop asks. You can then File → Save as a .pbix.
                  4. 
      
                
      
                Make a copy of your file first. The script replaces each changed measure, column or relationship with its complete new definition, keeping its other settings, and adds any new relationships or measures you ticked. Data, Power Query and report pages are never touched by the script.

                External tools for Power BI
                What each one is for, and what this page already covers
                
      
                Desktop tools such as DAX Studio and Tabular Editor have to be installed on your PC, because they connect to the model running inside Power BI Desktop. When installed, they appear on the External tools ribbon, and Power BI Desktop passes them the server and port so they connect automatically. A browser page can't do that, so this page rebuilds the analysis parts it can, from files you give it. Those are marked Built into this page.
